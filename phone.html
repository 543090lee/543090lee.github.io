One-time setup

This page saves straight to your GitHub repo, so it needs a token with permission to write to it. It's stored only in this browser and never leaves your phone except to talk to GitHub.

  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: foodie-phone
  3. Expiration: 1 year (you'll redo this step when it lapses)
  4. Repository access → Only select repositories → 543090lee/543090lee.github.io
  5. Permissions → Repository permissions → Contents → Read and write
  6. Generate token, copy it, paste below
